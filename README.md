# PythonPortfolio
AP CSP projects - 2026

1. Guess the Word (CreateTask)
A terminal‑based word‑guessing game inspired by Wordle. Players have seven attempts to guess a randomly selected five‑letter word, with optional hints and feedback on letter accuracy.

Key Features
Random word selection based on difficulty
Hint system revealing specific letter positions
Input validation and feedback on correct/misplaced letters
Tracks win/loss outcomes

Skills Demonstrated
File handling with Pandas
Conditional logic and loops
User input validation
Game design fundamentals

2. Hogwarts House Sorter
A fun interactive program that assigns users to a Hogwarts house based on their name or a randomized selection.

Key Features
Recognizes specific character names
Random house assignment for unknown names
Dramatic timed pauses for effect

Skills Demonstrated
Conditional branching
Randomization
User interaction and input handling

3. Dog Breed Recommender
A recommendation tool that suggests a dog breed based on the user’s experience level and living space. Opens a browser link with more information and prints a detailed description.

Key Features
Personalized breed recommendations
Opens relevant breed info in the browser
Includes curated descriptions and sources

Skills Demonstrated
Decision trees
Webbrowser automation
Data organization using lists

4. Rock‑Paper‑Scissors Game
A classic Rock‑Paper‑Scissors simulation where the user plays against the computer. Tracks wins, losses, and draws across multiple rounds.

Key Features
Randomized computer choices
Score tracking across rounds
Replay loop with exit option
Countdown animation for immersion

Skills Demonstrated
Game logic and probability
Loops and state tracking
Input mapping and validation

5. Madlibs Story Generator
An interactive Madlibs game where users fill in prompts — or choose random options — to generate a humorous, personalized story.

Key Features

Bold text formatting using ANSI escape codes
Fully dynamic story generation

Skills Demonstrated
String formatting (f‑strings)
Randomization
User‑driven content generation
